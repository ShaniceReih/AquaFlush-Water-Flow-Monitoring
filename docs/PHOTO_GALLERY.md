# Prototype Photo Gallery

The images below were extracted from the team's May 2025 AquaFlush presentation (slides 6–7), not recreated or AI-generated. The photos document the exhibited prototype.

Once the original image files have been uploaded to `images/`, the gallery can be rendered directly in the README.

| Image filename | Description | Presentation slide |
|---|---|---|
| `images/drainage-prototype-overview.jpg` | Miniature street-and-drainage system with water container and piping | 7 |
| `images/arduino-wiring-and-relay.jpg` | Breadboard, Arduino-related wiring, and relay module inside the model | 6 |
| `images/lcd-display-overview.jpg` | Front-facing mounted I²C LCD in the physical model | 6 |
| `images/lcd-display-closeup.jpg` | Close-up LCD photographed displaying “Flow: 0 L/h” and “Pump: ON” | 7 |
| `images/pump-and-water-container.jpg` | Under-table water container and pump/hose setup | 6 |

## Important evidence note

The LCD photo does show a **pump status label**. However, the **recovered sole Arduino sketch** does **not** contain the code to display this text or operate a relay. This discrepancy cannot be resolved from the screenshot alone. We document what the photograph shows without attributing undocumented firmware features to the recovered code.

## Adding images

Extract the supplied `AquaFlush_Prototype_Photos.zip`. On GitHub open **Add file → Upload files**, drag the five files from the `images` folder to an `images/` folder in the repository, then commit. Images uploaded this way will have the exact filenames referenced here.
